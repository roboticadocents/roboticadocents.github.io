# Glosario catalán → castellano

Documento de trabajo de la rama `traduccion-es`. Las entradas marcadas con «(build)» afectan al texto que interpreta el generador: si se cambian, hay que actualizar el código y los tests.

## Cómo se usa

1. Se consulta antes de traducir un lote.
2. Si un término no está, se propone y se añade aquí antes de usarlo en varios archivos.
3. No se usan sinónimos distintos para el mismo concepto dentro del mismo bloque.
4. Los nombres de producto, el código y las rutas no se traducen.

- URLs y fuentes oficiales.
- Emojis.
- Números, unidades, tiempos y recuentos.
- Nombres propios y marcas.

## 10. Términos en revisión

- `títere` frente a `marioneta` para `titella`.
- `niño o niña` frente a `criatura` para `criatura`.
- `lista`, `matriz` o `array` para `matriu` y `array` en programación.
- `retroalimentación` frente a `feedback`.
- `detener` frente a `parar` para robots y trenes.
- `ordenador` (España) y no `computadora`.
