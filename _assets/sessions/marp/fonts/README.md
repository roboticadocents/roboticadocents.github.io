# Fonts de les presentacions

Sora i Plus Jakarta Sans, distribuïdes sota SIL Open Font License 1.1.
Les llicències completes es conserven en aquesta carpeta.

Fonts originals:
- https://github.com/google/fonts/tree/main/ofl/sora
- https://github.com/google/fonts/tree/main/ofl/plusjakartasans

Els fitxers TTF són instàncies estàtiques de les fonts variables originals,
amb pesos 400 (fitxer sense sufix) i 700 (`-Bold`). S’han generat amb
`fontTools.varLib.instancer.instantiateVariableFont` per mantindre el text
seleccionable en les exportacions PDF de Chromium.
